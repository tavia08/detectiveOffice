이 압축파일은 현재 GitHub detectiveOffice 저장소에 덮어쓰기 위한 최종 적용본입니다.

적용 방법
1. 압축을 풉니다.
2. index.html을 기존 저장소의 index.html에 덮어씁니다.
3. source_data 폴더를 저장소 루트에 추가하거나 기존 source_data를 통째로 교체합니다.
4. GitHub Desktop에서 변경 사항을 확인한 뒤 Commit → Push 합니다.

→ 탐정수첩·스탬프
