역사탐정사무소 탐정수첩 스탬프 통합 패치

적용 내용
- 대표 사료수사 31개를 메인 탐정수첩에 추가
- 기존 44개 사건은 '추가 수사 스탬프'로 별도 구역 유지
- 탐정수첩 상단에 대표/추가/전체 스탬프 진행 수 표시
- 대표 사료수사 31개용 source_stamps SVG 스탬프 추가
- 대표 수사 카드 클릭 시 해당 대표 사료수사로 이동
- 추가 수사 카드 클릭 시 기존 사건으로 이동
- 획득 상태는 기존 localStorage 키를 그대로 사용

적용 방법
1. index.html 덮어쓰기
2. source_stamps 폴더를 저장소 루트에 추가
3. source_data / case_data / stamps / assets는 그대로 유지

주의
- 이번 스탬프는 역사 유물 사진이 아니라 앱용 그래픽 도장입니다.
- 실제 유물 이미지 스탬프로 바꾸고 싶다면 source_stamps 폴더의 SVG 파일만 같은 이름으로 교체하면 됩니다.
