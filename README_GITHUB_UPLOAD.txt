역사탐정사무소 GitHub 업로드용 스탬프 패치

포함 파일
- index.html
- source_stamps/

적용 방법
1. detectiveOffice 저장소 루트의 index.html을 이 파일로 덮어쓰기
2. source_stamps 폴더를 저장소 루트에 추가 또는 기존 폴더와 병합
3. 기존 source_data / case_data / stamps / assets는 그대로 유지
4. GitHub Desktop에서 Commit to main → Push origin
5. GitHub Pages 반영 후 브라우저에서 Ctrl+F5

반영 내용
- 대표 사료 수사 31개를 메인 탐정수첩에 표시
- 대표 사료 수사와 기존 추가 수사 스탬프 영역 분리
- 대표 사료 수사 스탬프 진행률 표시
- 단원별 색상 통일 스탬프 PNG 10종 적용
  · 1단원: SOURCE-1-1 ~ SOURCE-1-6
  · 2단원: SOURCE-2-7 ~ SOURCE-2-10
- 나머지 대표 사료 수사는 기존 SVG 스탬프 사용

주의
- source_stamps 폴더 안의 PNG와 SVG를 모두 함께 업로드해야 합니다.
- 기존 source_data 폴더를 삭제하지 마세요.
